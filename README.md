# mustio.co

Coder Mustafa'nın ilk web sitesi. Saf HTML, CSS ve JavaScript ile yazıldı.

## Yayına alma (GitHub Pages)

1. Bu klasördeki dosyaları GitHub repona yükle.
2. Repo'da **Settings → Pages** bölümüne git.
3. Branch olarak `main` seç ve kaydet.
4. Bir dakika sonra siten yayında olur.

## Düzenlenecek yerler

- `index.html` içinde `KULLANICI_ADIN` yazan yerlere GitHub kullanıcı adını yaz.
- `adin@ornek.com` yerine kendi e-posta adresini yaz.
